# Datalogos Product Ecosystem Standalone Demonstration · v1.5

Self-contained local demonstration of Datalogos Limited’s product ecosystem: Counterpoise, Verity, Datafolio and Hyphvera.

Open `index.html` in a modern browser. No installation, account, server, cloud service, API or internet connection is required.

Includes an interactive Counterpoise overview, four independent control domains (Governance, Privacy, Ethics and Security), Verity assurance views, a Datafolio wallet experience and a Hyphvera federated catalogue view with stewardship and source-change signals. The technical section includes full-system, modular, decision-sequence and data-flow diagrams.

The product marks in the interface are vector assets reproduced from the supplied September 2026 Datalogos master identity concept deck. That deck identifies these marks as concepts awaiting final production approval and legal clearance. Interface copy and visual hierarchy follow the supplied Datalogos/AIdentity/Counterpoise/Verity/Datafolio/Hyphvera identity guidance.

All content and data are illustrative. The demonstration does not connect to services, Kafka, source systems or catalogues; issue credentials; store customer data; call APIs; or transmit information. Hyphvera source, owner, freshness and event data are illustrative only.
