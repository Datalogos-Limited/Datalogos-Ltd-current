# Counterpoise Standalone Demonstration · v1.4

Self-contained local demonstration for Counterpoise, an assurance platform from Datalogos Limited.

Open `index.html` in a modern browser. No installation, account, server, cloud service, API or internet connection is required.

Includes an interactive overview, four independent domain modules (Governance, Privacy, Ethics and Security), Verity assurance views, and a dedicated Datafolio wallet experience. The technical section includes full-system, modular, decision-sequence and data-flow diagrams.

The product marks in the interface are vector assets reproduced from the supplied September 2026 Datalogos master identity concept deck. That deck identifies these marks as concepts awaiting final production approval and legal clearance. Interface copy and visual hierarchy follow the supplied Datalogos/AIdentity/Counterpoise/Verity/Datafolio identity guidance.

All content and data are illustrative. The demonstration does not connect to services, issue credentials, store customer data, call APIs or transmit information.
